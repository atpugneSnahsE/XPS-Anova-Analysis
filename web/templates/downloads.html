🚀 Quick Start

  1. Download the latest release ZIP file below
  2. Extract the ZIP file to your computer
  3. Windows: Double-click start_web.bat
  4. Mac/Linux: Run bash start_web.sh in Terminal
  5. Upload your Excel file and click "Analyze"
  6. Download your results

⚙️ System Requirements

  • Python 3.11+ (automatically checked and installed if needed)
  • 4 GB RAM minimum (8 GB recommended)
  • 1 GB free disk space (more for large analyses)
  • Windows 7+, macOS 10.13+, or modern Linux
