💻 Installation Instructions

Windows Users

  1. Download the ZIP file above
  2. Right-click → Extract All
  3. Open the extracted folder
  4. Double-click start_web.bat
  5. Your browser opens automatically → Upload your file → Click "Analyze"

Mac/Linux Users

  1. Download the ZIP file above
  2. Extract the ZIP file
  3. Open Terminal
  4. Navigate to the folder: cd /path/to/ANOVA
  5. Run: bash start_web.sh
  6. Your browser opens automatically → Upload your file → Click "Analyze"

Command Line (Advanced)

# XPS analysis only
python main.py

# Full ANOVA pipeline
bash start.sh anova
